# Model Artifacts

The original Edge Impulse deployment exports are preserved separately from this public-facing repository.

The exported library contains:

- the generated model parameters;
- the compiled TensorFlow Lite model;
- MFE preprocessing configuration;
- classification labels;
- Edge Impulse inference SDK;
- embedded inference support code.

The labels preserved by the export are:

```text
ai_voice
human
```

The public repository intentionally does not redistribute the complete generated Edge Impulse SDK/model export. Check the applicable Edge Impulse terms before publishing those generated files publicly.
